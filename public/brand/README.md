Este directorio guarda la identidad visual sustituible de CubiOps.

Archivos:

- mark.svg / mark-dark.svg — símbolo (cubo abierto + flujo)
- logo.svg / logo-dark.svg — símbolo + palabra CubiOps
- El favicon vive en /public/favicon.svg
- apple-touch-icon.png e icon-512.png se generan con `npm run assets`

Sustituye estos SVG cuando exista un logo definitivo. Los componentes de la web apuntan a estas rutas o al componente CubeMark, que replica el mismo trazo.
